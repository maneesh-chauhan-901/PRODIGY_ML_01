PRODIGY_ML_01 — Machine Learning Internship Task

The objective of this project is to build a Machine Learning model that predicts house prices based on different features of a property.

📊 Dataset

The project uses a housing dataset containing various features such as:

Overall quality
Living area
Number of bedrooms and bathrooms
Garage information
Year built
Other property-related attributes
🛠️ Technologies Used
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Jupyter Notebook
🤖 Machine Learning Model

The project uses Linear Regression to predict house prices.

The main steps include:

Loading and exploring the dataset
Data preprocessing and handling missing values
Selecting relevant features
Splitting data into training and testing sets
Training the Linear Regression model
Making house price predictions
Evaluating model performance
📈 Model Evaluation

The performance of the model can be evaluated using regression metrics such as:

Mean Absolute Error (MAE)
Mean Squared Error (MSE)
Root Mean Squared Error (RMSE)
R² Score
